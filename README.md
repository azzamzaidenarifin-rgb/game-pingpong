# game-pingpong

Proyek game arcade 2D klasik yang dikembangkan untuk mengimplementasikan logika pemrograman dasar, sistem koordinat, dan mekanika fisika sederhana (pantulan bola).

## 🎯 Tujuan Proyek
* Penerapan Coding 2D: Menguji pemahaman logika pemrograman sederhana yang 2D
* Melatih Fokus & Ketangkasan: Menguji refleks dan koordinasi pemain dalam mengontrol stick
* Hiburan (Entertainment): Menyediakan sarana permainan kasual yang ringan dan menyenangkan

## 🎮 Cara Bermain
1. Jalankan berkas program utama.
2. game ini dijalankan secara endless
3. Gunakan kontrol keyboard W S untuk menggerakkan stick 1 dan UPARROW dan DOWNARROW untuk menggerakkan stick 2
4. Jangan biarkan bola melewati stick-mu untuk mendapatkan skor untuk dapat rekor tertinggi
